# 🎧 Spotify Data Analysis Dashboard (Power BI)

A comprehensive, interactive dashboard for visualizing and analyzing **simulated/generated Spotify streaming data**. This project demonstrates end-to-end data transformation and visualization skills, turning structured data into insightful metrics, trends, and charts.



## ✨ Dashboard Capabilities

This dashboard provides a deep dive into listening data across three views:

### 🏠 Overview Tab
* **Key Metrics:** Total **Songs**, **Artists**, **Average Min** listened per song, and **Average Popularity**.
* **Content Breakdown:** Distribution of songs by **album_type** (single vs. album) and **Explicit/Non-Explicit** status.
* **Timeline Analysis:** Charts showing **Popularity by Month** and **Songs by Month**, revealing listening trends throughout the year.
* **Top Content:** Rankings for **Artist Songs** and **Songs by Artist**.

### 🎤 Artists Tab
* **Artist Demographics:** Bar charts displaying **Distinct Artists by song**.
* **Popularity Insights:** Charts for **Total Popularity by Song** and **Avg Hits by Artist**.
* **Detailed Artist Table:** A dynamic table providing a comprehensive breakdown: **Songs**, **album_type** count, **Hits Song** count, **Avg Tracks Per Album**, and **Avg Popularity**.

### 🎵 Songs Tab
* **Song Metrics:** A sortable and filterable table listing individual songs with metrics like **album_type**, **Month** released/streamed, **Avg Popularity**, **Min/Max Popularity**, and **Avg Duration (Minutes)**.

---

## 🛠️ Technology Stack

* **Platform/Visualization Tool:** **Microsoft Power BI Desktop**
* **Data Preparation:** **Spreadsheets** for initial data cleaning and ETL from the raw or simulated data source.
* **Data Source:** **Generated/Sample Spotify Streaming Data** designed to mimic real-world listening behavior.
* **Languages/Tools Used:** **Power Query (M language)** for data transformation within Power BI, and **Data Analysis Expressions (DAX)** for creating measures and calculated columns.
